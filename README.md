# AR Watch Try-On

1. Install Node.js 18+ from https://nodejs.org
2. In this folder:  npm install
3. Start:           npm run dev
4. Desktop: open https://localhost:5173 (accept the certificate warning)
5. Android: phone on the same Wi-Fi, open the "Network:" URL shown in the terminal
   (e.g. https://192.168.x.x:5173), tap Advanced -> Proceed, allow the camera.
6. Hold a credit card flat against your wrist inside the outline, press "Start 5s Timer".

Watch model: public/models/watch_reference.glb. Tip: use even, front lighting; avoid backlight.
